Web-Based Banking System – Software Quality Assurance & Testing
Project Overview:
This project focuses on evaluating the functionality, quality, and reliability of a Web-Based Banking System through structured software testing activities. It covers test planning, test case design, functional testing, Selenium IDE-based automation testing, database validation, and test result documentation.

Project Objectives:
- Evaluate system functionality and reliability.
- Identify defects and inconsistencies.
- Verify system features against expected requirements.
- Perform manual and automated testing.
- Validate system behavior and database changes.

 Testing Scope:

The project covers the following modules:

- User Registration
- User Login
- Fund Transfer
- Utility Bill Payment
- Transaction History
- Admin Dashboard

 Testing Activities:

 1. Software Test Planning
- Prepared a Software Test Plan.
- Defined testing scope, objectives, and approach.
- Identified functional and non-functional testing considerations.

 2. Test Case Design and Execution
- Designed and executed test cases for major banking functionalities.
- Compared actual results with expected results.
- Covered positive and negative test scenarios.

 3. Functional Testing
- Tested user authentication and banking operations.
- Verified fund transfer and bill payment workflows.
- Checked transaction history and administrative functionalities.

 4. Automation Testing
- Used Selenium IDE to automate selected banking workflows.
- Automated user login, loan requests, fund transfers, and utility bill payments.
- Reviewed automation execution results.

 5. Database Validation and Reporting
- Validated relevant database changes after test execution.
- Identified and documented defects.
- Prepared test execution results and testing documentation.
